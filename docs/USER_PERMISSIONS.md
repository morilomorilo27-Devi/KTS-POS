# تخصيص صلاحيات المستخدمين

من **الإدارة ← المستخدمون ← تخصيص الصلاحيات**، يحدد مدير النظام وصول كل مستخدم إلى الأقسام والإجراءات.

- **حسب الدور:** الإعداد الافتراضي للدور، مع مراعاة إتاحة القسم الأساسي.
- **سماح مخصص:** يمنح الإجراء للمستخدم إذا كان القسم الأساسي متاحًا له.
- **منع مخصص:** يمنع الإجراء لهذا المستخدم دون تغيير صلاحيات بقية مستخدمي الدور.

تتضمن النافذة البحث، وتطبيق قرار على مجموعة كاملة، واستعادة إعدادات الدور، ومعاينة الصلاحيات الفعلية، وملاحظة اختيارية تسجل مع التعديل.

يمكن مثلًا السماح بعرض الأصناف مع منع الإضافة والتعديل والتعطيل، أو السماح بعرض أوامر الشراء دون الاستلام، أو عرض فواتير الموردين دون السداد.

يحفظ المستخدم الجديد أولًا بدوره الأساسي، ثم تخصص صلاحياته من صفه في الجدول. عند تغيير الدور لاحقًا تبقى التخصيصات الفردية محفوظة، وتحتسب القرارات الموروثة وفق الدور الجديد.

تطبق قرارات الوصول على الخادم في الطلب التالي، بما يشمل الطلبات المباشرة والمزامنة. تحدث الواجهة صلاحياتها عند استعادة التركيز أو اكتشاف تغيرها أثناء طلب للخادم. تعمل الوظائف المحلية دون اتصال وفق آخر صلاحيات معروفة؛ تعاد مراجعة الصلاحيات الحالية عند المزامنة.

تخصيص الصلاحيات محصور بمدير النظام المخول. يمنع النظام إزالة آخر مدير فعال قادر على إدارة المستخدمين والصلاحيات. تسجل جميع تغييرات التخصيص بقيمها السابقة والجديدة في سجل التدقيق، وتمنع النافذة الكتابة فوق تعديل أحدث جرى بعد فتحها.

ملفات التنفيذ: `server/src/services/permissionService.js` و`client/js/user-permissions.js`.
