# هوية واجهة الإدارة

تحديث بصري شامل لأقسام الإدارة الثمانية عشر، دون تغيير قواعد البيع أو المحاسبة أو صلاحيات الوصول.

## الهوية
- أخضر بترولي للتنقل والإجراءات الرئيسية: `#123a37` و`#245d56`.
- نعناعي فاتح للاختيار والملخص: `#d9edbf`.
- أزرق للتحصيل، عنبري للمخزون، وبنفسجي للورديات؛ مع تسميات نصية ترافق الألوان.
- أيقونات SVG محلية، اتجاه عربي RTL، وتخطيط متجاوب للهاتف والأجهزة اللوحية وسطح المكتب.

## الملفات
- `client/css/admin.css`: تنسيق الإدارة والنماذج المشتركة أثناء العمل داخل الإدارة.
- `client/js/admin-design.js`: الأيقونات، التنقل المجمع، بطاقات المؤشرات، الجداول، ورسوم البيانات ومعاينة إعدادات الفرع.
- `client/js/admin.js`: إجراءات الأقسام ونماذجها، البحث وصفحات الجداول (20 سجلًا للصفحة).
- `client/sw.js`: تخزين ملفات التصميم محليًا مع إصدار جديد للذاكرة المؤقتة.

## سلوك البيانات
تعتمد مؤشرات الملخص ورسوم الفئات والتحصيل على واجهات التقارير الفعلية. تظهر حالة فارغة عند غياب المبيعات. معاينة إعدادات الفاتورة لا تحفظ التعديلات؛ الحفظ يتم بالزر المعتاد. البحث يشمل جميع السجلات المحملة قبل تقسيمها إلى صفحات.

## التحقق
`npm test` لاختبارات النظام، و`node docs/browser-test.cjs` لاختبارات المتصفح. يستخدم اختبار المتصفح قاعدة مؤقتة مستقلة ويزيلها بعد الانتهاء. يغطي الأقسام الثمانية عشر، البحث والتصفح، نماذج الإدخال، معاينة الفرع، غياب البيانات، عروض 390 و768 و1366 و1920، ومسار البيع والعمل دون اتصال. تُحفظ لقطات المراجعة في `docs/test-output/`، وتتضمن بيانات اختبار فقط.
